# 月轮观 · 八狱考据

《影之诗：超凡世界》「复苏的阿兹弗特 / Revenants of Azvaldt」官方角色介绍页的考据扩展版。

## 打开方式

需要通过 HTTP 打开（页面用了 fetch 式加载与 iframe），不能直接双击 index.html。

```bash
cd "项目根目录"
python -m http.server 8902
# 浏览器打开 http://127.0.0.1:8902/
```

## 在线访问（GitHub Pages）

仓库已配置为 GitHub Pages站点，访问：

```
https://penghuo258.github.io/-/
```

若未生效，在仓库 **Settings → Pages** 中把 Source 设为 `main` 分支、`/ (root)`。

所有资源使用相对路径（`archive/assets/…`），因此在子路径部署下无需额外配置。

## 两个视图

顶部中央有「考据卷 / 原站」切换按钮。

### 考据卷（默认）
以佛学考据为主体，**所有内容直接铺在页面上，不需要点开任何弹窗**：

- **总论**：月轮观、缺月与满月、四魔、他化自在天、变貌（《大般涅槃经》引文）
- **八对**：八层监狱 × 每层两名角色。每层包含楼层标题 + 两名角色卡
- **附录**：泽勒尔与帝释天的变貌

**角色卡排版对齐官方页**：

| 元素 | 规格 | 来源 |
|---|---|---|
| 立绘 | 出血式居中，桌面 2800×1744 / 移动 750×975 | 官方 `charaN_img` srcset |
| 阵营行 | 阵营图标 + 名称，24px | 官方 `flex items-center gap-8 text-[24rem]` |
| 角色名 | 50px / PC 40px，阵营色渐变文字 | 官方 `h3 text-[50rem]` + `to-{faction}` |
| 编号 | 右上竖排旋转 | 官方 `rotate-90` |
| 官方简介 | 20px Noto Sans SC，行高 2.1 | 官方 `font-sans text-[24rem] leading-relaxed` |
| 楼层名 | 50px / PC 40px，阵营色渐变 | 官方楼层标题 |

每个角色卡下半部分是考据正文（衬线字体，与官方 sans 正文形成层次）：位分、佛学原型、剧情概述、分节释义、经文引述。

立绘用 `<picture>` 按屏宽自动切换，移动端加载轻量版。

顶部有楼层跳转胶囊，滚动时自动高亮当前层。

### 原站
在 iframe 中完整载入官方页面，原始信息与视觉一比一保留。

## 目录结构

```

backup/
  01-原站+弹窗版/    第一版：原站 + 解读浮层
  02-考据卷初版/      第二版存档：考据卷初版（双栏信息条布局）
```

## 备份

改动前先存档，可随时回退：

- `backup/01-原站+弹窗版/` —— 原站 + 解读浮层
- `backup/02-考据卷初版/` —— 考据卷初版

## 构建脚本

| 脚本 | 作用 |
|---|---|
| `build_original.py` | 解 mhtml 快照 → 资源本地化 → 清 SvelteKit 运行时 |
| `inject_overlay.py` | 向原站页面注入解读浮层容器 |
| `normalize_data.py` | 规范解读数据格式（多个 `p` 合并为数组） |
| `fetch_assets.sh` | 补齐原站 PC 高清资源变体 |
| `verify_cdp.py` | CDP 验证工具（自写最小 WebSocket 客户端） |
